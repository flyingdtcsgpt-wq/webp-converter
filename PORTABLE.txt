WebP·PNG 변환기 - 포터블 버전 (설치 필요 없음)
================================================

[사용법]
1. 압축을 풀고 WebPConverter 를 실행하세요. (설치 없음)
2. 폴더(또는 USB)째 다른 PC로 옮겨도 그대로 실행됩니다.
3. 지우려면 파일/폴더만 삭제하면 끝입니다.

[설정 저장]
- 설정은 프로그램 바로 옆의 WebPConverter.settings.json 에 저장됩니다.
- 윈도우 레지스트리, 사용자 폴더에는 아무것도 남기지 않습니다.
- 프로그램 폴더에 쓸 수 없으면(읽기 전용 USB, Program Files 등) 사용자 폴더에 저장됩니다.

[처음 실행할 때 보안 경고]
- Windows : "Windows의 PC 보호" 창 → 추가 정보 → 실행
            (서명되지 않은 프로그램이라 나오는 안내입니다)
- macOS   : 앱을 우클릭 → 열기.  안 열리면 터미널에서
            xattr -cr /앱이/있는/경로/WebPConverter.app
            앱은 압축 폴더에서 꺼내 다른 폴더로 옮긴 뒤 실행하세요.

[Windows 파일 종류]
- WebPConverter-Windows-Portable.zip : 폴더형. 압축을 풀고 WebPConverter\WebPConverter.exe 실행. 시작이 빠르고 백신 오탐이 적음 (추천)
- WebPConverter-Windows-SingleFile.exe : 파일 하나. 아무 곳에나 두고 실행. 켤 때마다 임시로 풀어서 시작이 몇 초 느림

[참고]
- 압축 파일(ZIP 등)을 처리할 때만 임시 폴더를 사용하고, 끝나면 지웁니다.
- 자세한 설명: 프로그램의 [도움말·주의사항] 버튼 또는 F1 키
